# Windows API represented-family source audit

Audit completed 2026-08-24. For every baseline contract below, the review read the official Microsoft Learn Syntax, Parameters, Return value, Remarks, and Requirements sections, then followed the directly relevant encoding, extended, replacement, or similarly named sibling pages. Native facts come only from Microsoft Learn. The decisions are compact paraphrases: a sibling is included only when target, completion/synchronization model, output contract, and ownership remain the same operation. Large value sets show the course-relevant subset in the guide and link to Microsoft's complete list.
